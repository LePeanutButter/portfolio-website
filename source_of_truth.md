## UI Guide From `portafolio-example.html`

### Design Language

- Premium minimalist style inspired by Vercel, Apple, and Linear.
- Clean, spacious, high-contrast layout.
- Lightweight cards, subtle shadows, and restrained microinteractions.
- Technical personality shown through code-card motifs and monospace accents.
- Smooth scrolling, fade-in entrance animation, hover lifts, and header state changes on scroll.

### Layout

- Global max-width container of approximately `1100px`.
- Fixed translucent header with backdrop blur.
- Hero occupies the first viewport with large typographic hierarchy.
- Interactive code card follows the hero as a visual proof of craft.
- Projects are displayed in a responsive grid using `repeat(auto-fit, minmax(300px, 1fr))`.
- Footer is separated by a subtle top border and contains social/contact links.
- Mobile layout hides nav links, stacks hero actions, and keeps primary CTA full width.

### Typography

- Sans font: Inter.
- Monospace font: JetBrains Mono.
- Hero title: heavy weight, large clamp sizing, tight line-height.
- Body copy: lighter weight, generous line-height, muted secondary text.
- Technical tags and code snippets use monospace styling.

### Color Scheme

- Principal background: `#fafafa`
- Card background: `#ffffff`
- Primary text: `#000000`
- Secondary text: `#666666`
- Muted text: `#888888`
- Subtle border: `rgba(0, 0, 0, 0.08)`
- Availability green: `#00cc66`
- Code syntax accents:
  - Keyword blue: `#0000ff`
  - Property purple: `#660099`
  - String green: `#008000`
  - Comment gray: `#a0a0a0`
  - Number blue: `#0984e3`

### Components

- Fixed glass header with blurred background and thin border.
- Rounded availability badge with small green status dot.
- Primary black CTA button that inverts on hover.
- Secondary text CTA with arrow and horizontal hover movement.
- Code card with macOS-style traffic-light dots.
- Project cards with white backgrounds, 12-16px radius, subtle borders, and hover lift.
- Monospace project tags with pale background and thin border.
- Social footer links with animated underline.

### Interaction Notes

- Use subtle motion only: opacity, translateY, small hover lifts, and gentle card tilt.
- Keep animation timing smooth with cubic-bezier behavior similar to `cubic-bezier(0.16, 1, 0.3, 1)`.
- Maintain a restrained, professional tone rather than decorative visual overload.
- Preserve the portfolio's technical personality through actual project evidence, not filler copy.
